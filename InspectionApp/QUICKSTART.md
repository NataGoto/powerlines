# Быстрый старт

## За 5 минут до первого запуска

### 1. Установка зависимостей

```bash
cd InspectionApp
npm install
```

### 2. Запуск

```bash
npx expo start
```

### 3. Открыть на телефоне

**Вариант А: Expo Go (быстро)**
1. Установите Expo Go из Google Play
2. Отсканируйте QR код из терминала
3. Готово!

**Вариант Б: Эмулятор Android**
```bash
# В терминале нажмите 'a' после npx expo start
```

**Вариант В: Сборка APK (для продакшена)**
```bash
npm install -g eas-cli
eas login
eas build --platform android --local
```

## Первый тест

1. Введите объект: `Тест_1`
2. Введите элемент: `Комната_1`
3. Нажмите **ФОТО**
4. Сделайте фото
5. Автоматически откроется экран аудио
6. Нажмите **ПРОПУСТИТЬ** (или запишите комментарий)
7. Готово! Проверьте файлы в папке приложения

## Проверка результата

Файлы сохраняются в:
```
Android: /storage/emulated/0/Documents/InspectionApp/
```

Должны быть созданы:
- `Тест_1_Комната_1_001.jpg`
- `Тест_1_Комната_1_001.m4a` (даже если пропустили аудио!)
- `session_metadata.json`

## Основной workflow

```
Главный экран
    ↓ (ввод объект + элемент)
Камера
    ↓ (съемка)
Аудиозапись
    ↓ (запись ИЛИ пропуск)
Сохранение пары файлов
    ↓
Главный экран
```

## Горячие клавиши (в терминале)

- `a` - открыть на Android
- `i` - открыть на iOS
- `w` - открыть в браузере
- `r` - перезагрузить приложение
- `m` - показать меню

## Troubleshooting

**"Cannot find module expo"**
```bash
npm install
```

**"Failed to build"**
```bash
rm -rf node_modules
npm install
```

**"Camera permission denied"**
- Зайдите в Настройки → Приложения → Expo Go → Разрешения
- Включите Камера и Микрофон
