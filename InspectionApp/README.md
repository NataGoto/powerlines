# Inspection App

React Native (Expo) приложение для структурированной фотофиксации с обязательными аудиокомментариями.

## Ключевая особенность

**Каждое фото ВСЕГДА имеет парный аудиофайл** - это гарантирует целостность данных для последующей обработки. Даже если комментарий пропущен, создается пустой `.m4a` файл.

## Рабочий процесс

### 📸 Фоторежим

1. Ввод объекта (например: "ТП1", "Склад_А")
2. Ввод элемента (например: "РУ_10кВ", "Отсек_1")
3. Нажатие "ФОТО" → камера
4. Съемка фото
5. **АВТОМАТИЧЕСКИЙ** переход к записи комментария
6. Запись комментария ИЛИ пропуск (создается пустой файл)
7. Возврат к главному экрану

### Именование файлов

```
Объект_Элемент_001.jpg
Объект_Элемент_001.m4a  ← ВСЕГДА есть (может быть пустым)
Объект_Элемент_002.jpg
Объект_Элемент_002.m4a
```

Пример:
```
ТП1_РУ10кВ_001.jpg
ТП1_РУ10кВ_001.m4a
ТП1_РУ10кВ_002.jpg
ТП1_РУ10кВ_002.m4a
```

## Метаданные

Файл `session_metadata.json` содержит:

```json
{
  "session": {
    "date": "2024-03-15",
    "startTime": "14:30:00",
    "project": "Обследование_ПС_Северная"
  },
  "records": [
    {
      "id": "ТП1_РУ10кВ_001",
      "photo": {
        "filename": "ТП1_РУ10кВ_001.jpg",
        "timestamp": "2024-03-15T14:30:22.123Z",
        "gps": {
          "latitude": 55.7558,
          "longitude": 37.6173
        }
      },
      "audio": {
        "filename": "ТП1_РУ10кВ_001.m4a",
        "duration": 45.5,
        "hasContent": true,
        "segments": ["original"]
      }
    }
  ]
}
```

## Установка и запуск

### Требования

- Node.js 18+
- npm или yarn
- Expo CLI
- Android Studio (для эмулятора) или физическое устройство

### Установка

```bash
# Клонировать или распаковать проект
cd InspectionApp

# Установить зависимости
npm install

# Запустить Expo
npx expo start
```

### Запуск на устройстве

1. Установите Expo Go из Google Play
2. Сканируйте QR код из терминала
3. Приложение откроется на телефоне

### Сборка APK

```bash
# Установить EAS CLI
npm install -g eas-cli

# Войти в Expo аккаунт
eas login

# Собрать APK локально
eas build --platform android --local

# APK будет в папке после сборки
```

Или для быстрой сборки:

```bash
# Сборка через Expo (требует аккаунт)
eas build --platform android
```

## Критические функции

### Атомарное сохранение пары файлов

```typescript
// fileManager.ts
static async savePhotoAudioPair(
  photoUri: string,
  audioUri: string | null,  // null = создать пустой файл
  object: string,
  element: string,
  counter: number
): Promise<{ photoPath: string; audioPath: string }>
```

**Гарантии:**
1. Всегда создается ОБА файла (.jpg + .m4a)
2. Если аудио нет - создается пустой валидный M4A файл
3. При ошибке оба файла удаляются (откат)
4. Метаданные обновляются только после успешного сохранения

### Режим удержания для аудио

```typescript
<TouchableOpacity
  onPressIn={startRecording}   // Начать при нажатии
  onPressOut={stopRecording}   // Остановить при отпускании
>
  <Text>🎤 ДЕРЖАТЬ</Text>
</TouchableOpacity>
```

## Тестирование

### Проверка атомарности

1. Сделать фото
2. Пропустить аудио
3. Проверить что создан пустой `.m4a` файл
4. Проверить `session_metadata.json`:
   - `hasContent: false`
   - `duration: 0`

### Проверка предупреждения

1. Сделать 5 фото подряд
2. Пропустить аудио на всех
3. На 6-м фото должно появиться предупреждение

## Troubleshooting

### Камера не работает

1. Проверить разрешения в настройках Android
2. Перезапустить приложение
3. Проверить что expo-camera установлен: `npm list expo-camera`

### Аудио не записывается

1. Проверить разрешение на микрофон
2. Проверить что нет других приложений использующих микрофон
3. Попробовать режим удержания (не просто нажать, а держать)

### GPS не определяется

1. Включить GPS на устройстве
2. Дать разрешение на геолокацию
3. Выйти на улицу (в помещении может не работать)
