# Как добавить логотип

## Быстрая инструкция

### Шаг 1: Подготовить изображение

- Формат: PNG с прозрачным фоном (рекомендуется)
- Размер: 80x80 пикселей (или больше, будет масштабировано)
- Название файла: `logo.png`

### Шаг 2: Положить файл

```
InspectionApp/
  └── assets/
      └── logo.png  ← Сюда
```

Если папки `assets` нет, создайте её:
```bash
mkdir -p InspectionApp/assets
```

### Шаг 3: Обновить код

Откройте `src/screens/MainScreen.tsx` и найдите строку 133-136:

```tsx
{/* TODO: Заменить на <Image source={require('../../assets/logo.png')} style={styles.logo} /> */}
<Text style={styles.logoText}>ЛОГО</Text>
```

Замените на:

```tsx
<Image source={require('../../assets/logo.png')} style={styles.logo} />
```

Также удалите весь блок `logoPlaceholder` (строки 133-136) и замените на:

```tsx
<Image source={require('../../assets/logo.png')} style={styles.logo} />
```

### Шаг 4: Перезапустить приложение

```bash
npx expo start
# Нажмите 'r' для перезагрузки
```

## Альтернативный размер логотипа

Если хотите другой размер, измените в `src/constants/theme.ts`:

```typescript
export const layout = {
  logoHeight: 100,  // Измените на нужный размер
  logoWidth: 100,   // Измените на нужный размер
  // ...
};
```

## Примеры форматов

### Квадратный логотип (80x80)
✅ Рекомендуется

### Прямоугольный логотип
Укажите разные размеры:
```typescript
logoHeight: 60,
logoWidth: 120,
```

## Проверка

После добавления логотип должен появиться:
- На главном экране вверху
- Между верхним отступом и надписью "ЗиС Прогноз"

## Если логотип не отображается

1. Проверьте путь к файлу: `InspectionApp/assets/logo.png`
2. Перезапустите Metro bundler: Ctrl+C, затем `npx expo start`
3. Очистите кэш: `npx expo start --clear`

## Формат placeholder (текущий)

Сейчас используется серый квадрат 80x80 с текстом "ЛОГО" внутри.
После добавления настоящего логотипа он заменится на ваше изображение.
